# CC-3 workbench review and verification

Date: 2026-09-28. Prism: Gemini `gemini-3-flash-preview`.
Review ID: `bd44e86e31aab8295daad954c439d60d`.

| Finding | Disposition |
| --- | --- |
| Medium: `/usr/bin/open` is macOS-specific | Intentional. The supported release target and launcher are macOS. Keeping the fixed system executable avoids PATH-dependent browser launch. Linux launcher support is outside the current release contract. |
| Low: parameter mutations could be dropped while busy | Verified that `buttons()` disables project/experiment selectors and every parameter input/select synchronously when `mutation()` sets busy. Background refresh uses a separate `syncing` flag and does not suppress parameter mutations. No queue or automatic mutation replay was added. |

Validation: full `make check` passed. Headless Chromium 1.59.1 tests passed against a
real daemon and workload, covering a keyboard-driven first capture, a second capture,
shared baseline, measurement comparison, annotation text injection, exact export
preview/privacy, verified HTML download, mobile width, illustrative sample comparison,
a second unauthorized tab, loss of authorization on reload, and stale controls after
daemon shutdown. No JavaScript page errors occurred.

Go integration tests verify loopback-only binding, authentication on reads, exact
Host/Origin, cross-site/CSRF rejection, strict JSON, bounded proxy requests, route
allowlisting, no CORS, security headers, and no mutation on initial page load.

Desktop, mobile, and disconnected screenshots were inspected locally at
`.cache/workbench-main.png`, `.cache/workbench-mobile.png`, and
`.cache/workbench-disconnected.png`. Screenshots are regenerated by the browser test
and retained by its CI job. Test tokens travel only through a private IPC descriptor;
they do not enter screenshots or logs.

Manual screen-reader testing remains pending. Hardware behavior is outside this
software workbench verification and remains part of CC-5.
